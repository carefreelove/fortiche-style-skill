# Fortiche 前端风格

目标是让页面具有“影像放映 + 编辑排版 + 创作者手写批注”的节奏。先建立构图和字体层级，再添加动效。保留用户的品牌、信息结构、功能和既有技术栈。

## 使用方式

1. 阅读当前项目约定、页面内容和可用媒体。明确改动是整站、单页还是组件；没有既有项目时按需求选择最小可运行实现。
2. 实现前阅读 [design-system.md](references/design-system.md)。需要核对官网特征、区分实测与建议时阅读 [source-notes.md](references/source-notes.md)。这些记录足以离线使用；用户要求最新官网或精确复现时再重新调查。
3. 用一句话确定主视觉、标题层级、主要行动和表达强度。未指定时使用标准强度；保留内容密度与可读性，不能把“更有设计感”理解为增加所有装饰。优先完成一段高质量的“媒体 + 标题 + 元信息”组合，再展开其余内容。
4. 将 [fortiche.css](assets/fortiche.css) 作为可选样式起点。它是原创、带 `.ft` 作用域的基础样式，不是官网源码。按项目的 CSS、CSS Modules 或 Tailwind 体系转换，不强制替换现有样式系统。
5. [specimen.html](assets/specimen.html) 是可直接打开的构图样本与 HTML 结构示例。它用原创 SVG 代替影片素材，不代表官网截图或真实品牌内容；正式页面应使用与用户业务相关的媒体。
6. 完成功能与浏览器检查，再报告实际修改、运行方式和验证边界。

## 风格辨识度

按场景调整强度，无需为常规选择反复询问用户：

| 强度 | 适用场景 | 设计取舍 |
| --- | --- | --- |
| 轻量 | 既有产品、局部改造、信息较多 | 保留网格，应用色彩、标题对比和一处票券或旁注 |
| 标准 | 作品集、品牌首页 | 强主视觉、明暗章节、少量手写细节与交互反馈 |
| 鲜明 | 影视、创意工作室、活动专题 | 放大标题比例和画框表现，局部错向动效；仍保留阅读与操作路径 |

整页设计中建立以下关系；局部组件任务只应用相关部分，不扩展范围：

- **影像为主角**：大面积画面、明确焦点、极少覆盖文字；影片或摄影负责色彩和情绪。
- **标题像海报**：超大、窄体、紧凑的标题与安静的小号元信息形成强烈比例差。短英文可大写，中文使用可读的粗体和人工断行。
- **手写是旁白**：一小段倾斜批注、箭头或圈线回应当前内容；不要把正文全部手写化。
- **章节有明暗变化**：炭黑影像段落与纸灰文本段落交替，珊瑚红用于行动和反馈；辅助粉彩随项目画面选用。
- **界面像印刷物**：硬边、细分隔线、票根、竖排编号、小号标签；少量刻意错位，主要阅读轴稳定。
- **动效有角色**：画框反馈、注释浮现、轻微错向位移和章节入场。每个效果应强化某个内容关系。

素材不足时，用有主题的原创插画、静态海报或用户照片建立构图，明确暂用素材。不要用无关渐变填满页面后宣称已还原电影感。

## 内容与技术约束

- 提炼设计语言；默认使用用户自己的品牌、文案和素材，不把 Fortiche 的标识、影片、专有字体打包成可复用资产。不热链官网媒体作为生产依赖。
- 官网的 Druk / Monument Grotesk / Skribblugh 是字体角色证据。没有相应使用许可时，使用项目已有或许可明确的替代字体；窄体替代不等于完全相同。
- 不强制 WordPress、Elementor、GSAP 或 WebGL。普通 CSS 与少量 JavaScript 足以完成大部分效果；已有动画库时可复用。
- 用户只要求设计稿或风格分析时交付相应成果；要求实现时交付可运行代码和有效交互。
- CTA 指向真实动作；缺少目的地址时使用明确的本地演示流程或说明待接入项，不伪装提交成功。
- 标题级别按文档层级安排，手写文字使用样式类，不复制官网以 `h6` 表示手写样式的做法。

## 验收重点

- 桌面约 1440px 与手机约 390px 实际查看：标题不误裁，元信息可读，票券不拥挤，无意外横向滚动。
- 大标题、媒体和细节有清晰主次，不能退化为所有区域等大的圆角卡片网格。
- 检查菜单开关、键盘焦点、Escape、返回焦点、链接和视频播放/暂停；不要只验证 hover。
- 媒体慢加载、自动播放被拒绝、无视频或减少动态效果时，页面仍完整可用。
- 循环视频提供暂停方式；`prefers-reduced-motion` 下保留静态海报，禁用持续运动。触摸端不依赖悬停显示关键信息。
- 按既有项目运行适用的构建/检查。分别说明代码检查、浏览器验证、真实业务接入；未完成某项时不要表述为已验收。

## 常见调用

- “用 `$fortiche-style` 做一个动画工作室首页。” → 强影像、海报标题、作品元信息、票券式联系入口。
- “用 `$fortiche-style` 改造我的中文个人作品集。” → 保留个人内容，以中文粗体、作品大图和少量手写注释建立层次。
- “用 `$fortiche-style` 改一下后台的项目展示区域。” → 只改该区域，不把整个后台变成长滚动品牌站。
