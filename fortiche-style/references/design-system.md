# 设计系统与实现选择

以下色值来自官网公开样式；字号区间、动效预算与组件实现是适配建议，不是精确复制参数。

## 颜色与字体

| 角色 | 默认值 | 用法 |
| --- | --- | --- |
| ink | `#141414` | 深色章节、正文、细边线 |
| paper | `#ECEAE9` | 纸灰背景、深底主文字 |
| signal | `#FF364A` | 行动反馈、短注释、少量强调 |
| mint | `#C4FCD4` | 作品局部强调 |
| pink | `#EEC0F3` | 同上 |
| lavender | `#A494F9` | 同上 |
| sky | `#9BD2FC` | 同上 |
| butter | `#FFF098` | 同上 |
| neutral | `#CCC1B7` | 次级中性色 |

让纸灰、炭黑和影像占据主要面积，每章选一到两种强调色。不要把粉彩平均撒到所有组件。
正文优先 ink/paper 对比。signal 更适合装饰、边框或大字；小字放在 signal 背景上时优先 ink 并验证对比度，不默认用白色。

| 字体角色 | 官网声明 | 适配方法 |
| --- | --- | --- |
| 主标题 | Druk Bold | 许可明确的粗窄体，如项目已提供的 Anton、Bebas Neue；短词形成大色块 |
| 次级标题 | Druk Medium | 延续窄体骨架，尺寸低一级 |
| 正文与元信息 | Monument Grotesk | 项目已有 Grotesk、系统无衬线或许可明确的 Inter |
| 手写批注 | Skribblugh | 用户提供的手写体，或原创 SVG 箭头配正常文字 |

替代字体不保证字形一致。基础 CSS 不捆绑或远程加载字体；正式实现必须验证选用字体是否真的可用。
中文主标题可用本地 PingFang SC / 项目提供的 Noto Sans SC 等粗体；不要 `scaleX()` 压扁中文。中文正文不沿用英文大写或过紧字距，通常保持 `line-height: 1.5–1.7`。

建议比例：

- 英文海报标题：桌面约 `clamp(4rem, 12vw, 14rem)`，行高 `0.88–1`；长词必须试排。
- 中文主标题：约 `clamp(2.6rem, 7vw, 7.5rem)`，行高 `1.05–1.2`，按语义断行。
- 章节标题：`clamp(2.5rem, 6vw, 7rem)`；正文 16–20px，元信息 12–14px。
- 手写批注：22–42px，通常只占主标题的小部分；倾斜约 ±3–8°。
- 水平边距约 20–120px、章节间距约 64–180px，用 `clamp()` 调节。大字密度与章节留白共同建立节奏。

## 构图组件

### 放映首屏

先用静态 poster 完成构图，再增强为 `muted playsinline loop` 的视频。画面保持 `object-fit: cover`，逐个选择 `object-position`，不能让人脸被机械居中裁切。
顶部简练导航，中央或边缘保留一处播放入口。使用原创 SVG 画框或不规则边缘，在 hover/focus 时轻微变化；不要直接复用官网专属画框图片。
首屏通常占视口大部分；手机按主体比例重构。官网不是所有断点都满屏，因此不要强制 `100vh`。覆盖文字时增加必要遮罩。

### 编辑式文字章节

纸灰背景、夸张主词、注音/编号/短定义等小信息构成词条感。转译成创作理念、项目原则或服务描述，不复制官网自造词。
允许单个短标题、批注或装饰偏轴排列；正文与主要链接保持可靠网格。手机恢复单列阅读，不能靠横向溢出制造设计感。

### 作品海报

每个作品是一段视觉场景：大幅影像 + 短标题 + 一条 credits 式元信息。标题可靠近底边，元信息按“类别、角色、年份、合作方”等真实字段排列。
作品可纵向铺开或按实际需求做横向轨道。后台或搜索页仍可用紧凑列表，不能为复用首页构图牺牲检索效率。

### 手写注释与菜单

注释指向具体内容，例如作品旁的小箭头。纯装饰 SVG 使用 `aria-hidden="true"` 和 `pointer-events:none`；有信息量的文字必须可被辅助技术读取。
需要 overlay 菜单时，条目本身就是大排版元素，附少量注释。使用真实按钮、正确展开状态、焦点管理与 Escape 关闭；不能只有鼠标悬停才能看到入口。

### 票券 CTA

硬边矩形，主体放清楚的行动标题，票根放编号或方向箭头；用虚线、短线或缺口暗示电影票。条码若纯装饰，不承载关键信息。
默认纸灰底和细黑边，hover/focus 可转 signal 底与 ink 字。手机纵向叠放，整个链接可点，票根不挤压标题。用于少量高权重行动，不能把所有卡片都改成票券。

## 动效选择

| 对象 | 适配建议 | 降级 |
| --- | --- | --- |
| 链接/票券 | 180–300ms 色彩变化、2–4px 位移 | 颜色与 focus 提示 |
| 手写旁注 | 250–400ms 淡入和短距离移动 | 静态显示有用文本 |
| 章节入场 | 450–750ms，位移约 12–32px | 默认内容可见 |
| 错向文字 | 局部章节内小幅水平错向 | 手机/减少动态效果时静态 |
| 媒体放映 | 用户播放主影片；预览可静音循环 | poster、暂停开关与错误回退 |

不要将 Elementor 的 speed 字段当作 CSS 秒数。不默认引入滚动劫持、长时 pinning、自定义光标或持续闪烁；这些不是必要条件。
`prefers-reduced-motion` 同时处理 CSS 与 JavaScript/video；取消 CSS 动画不会停止视频。滚动动画使用可清理的观察/调度流程，避免每个元素持续监听并读取布局。

## 媒体和落地

- 首屏图像设置明确尺寸或 `aspect-ratio`，优先让 poster 及时出现。
- 下屏图像懒加载，视频接近视口再加载、离开时暂停；不要所有作品同时解码。
- 使用既有项目资源与组件；画框、箭头、票根可用原创 SVG/CSS 实现。
- 电影感依赖内容质量，仅靠颜色和动效不能保证同等效果。
- 真实文案录入后再确定断行，不为样例截图写死高度而让真实中文内容溢出。
