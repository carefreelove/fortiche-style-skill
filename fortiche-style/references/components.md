# 样例组件复用

样例位于 `assets/specimen.html`，样式在 `assets/fortiche.css`，可选交互在 `assets/specimen.js`。直接打开 HTML 即可运行；无需构建或第三方库。

## 按需拆分

| 组件 | HTML / CSS 入口 | 可选增强 |
| --- | --- | --- |
| 海报首屏 | `.ft-stage`、`.ft-stage-caption` | 画框的 hover/focus 反馈 |
| 作品展示 | `.ft-work-grid`、`.ft-project` | 按 `data-kind` 筛选 |
| 构图说明 | `.ft-project-details` 的 `details/summary` | 无，浏览器原生展开与键盘操作 |
| 全屏导航 | `#site-menu`、`.ft-menu-trigger` | `dialog.showModal()`、关闭及焦点恢复 |
| 票券入口 | `.ft-tickets`、`.ft-ticket` | 无，使用真实链接 |

保留 `.ft` 包裹层或将变量与选择器转换为项目的局部样式。所有布局组件并非必须同时引入；仅复用一张票券时无需引入菜单脚本或整页结构。

## 更换作品

- 每张作品保留标题、替代文本、分类、图像宽高和实际说明。原创 SVG 可替换为业务图片，但要重新检查裁切。
- `.ft-project-wide` 表示跨列主作品，其他作品在桌面为两列、手机为单列。宽幅主作品在手机使用单独的裁切焦点。
- 分类按钮的 `data-filter` 与作品的 `data-kind` 一致，`all` 表示全部。增加作品时同步更新静态按钮数量、章节总数和初始结果文字；实际筛选后的计数由脚本计算。
- 筛选后使用 `hidden` 移除无关作品，同时更新 `aria-pressed` 和结果提示。保持焦点在触发按钮上，不自动把用户滚动到列表底部。
- 不把纯静态海报标记为可播放影片。样例中的作品主题为虚构设计练习，迁移时换成真实内容。

## 导航与降级

- 菜单使用原生模态 `dialog`，背景交互由浏览器隔离。关闭按钮和 Escape 恢复触发按钮焦点；选择章节链接后，焦点转入带 `tabindex="-1"` 的目标章节。
- 只有 `showModal()` 可用且事件绑定完成后才显示菜单按钮。移动端也仅在增强成功后隐藏常规导航。
- 分类按钮初始隐藏，绑定完成后才显示。脚本加载失败时显示全部作品；原生折叠说明、导航链接和票券照常可用。
- CSS 提供 `prefers-reduced-motion` 覆盖。样例无持续动画；若后续加入视频或 JavaScript 动效，需要另行处理其暂停与减少动态效果逻辑。

移植后验证：分类往返、计数、折叠说明的键盘操作、菜单焦点循环、Escape、章节定位，以及脚本缺失时的导航。不要把本样例的浏览器检查视为其他框架实现也已通过验证。
